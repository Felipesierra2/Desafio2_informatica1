# UdeABook

UdeABook es una red social desarrollada en C++ utilizando el framework Qt. La aplicación permite a los usuarios registrarse, iniciar sesión y administrar sus perfiles mediante un nombre de usuario único.

Entre sus funciones principales se encuentran agregar amigos, visitar perfiles, recibir sugerencias de amistad, enviar y administrar mensajes, y organizar fotografías en álbumes. Además, cada fotografía almacena información como su fecha de captura y cantidad de «me gusta».

El proyecto utiliza programación orientada a objetos para organizar sus funcionalidades mediante clases, lo que facilita la modularidad, el mantenimiento y la ampliación del sistema.
